## Why TryHackMe first?

THM has structured learning paths with step-by-step guidance, unlike HTB which drops you in the deep end. Perfect for building foundational skills.

## Recommended Learning Paths

1. **Pre-Security** — absolute basics
2. **SOC Level 1** — blue team intro
3. **Jr Penetration Tester** — offensive basics
4. **Complete Beginner** — broad overview

## Free Rooms to Start

- `Linux Fundamentals` series
- `Networking Fundamentals`
- `OWASP Top 10`
- `Blue` (intro to Windows IR)
- `Basic Pentesting`

## Tips

- Use the built-in AttackBox if you don't have Kali
- Complete rooms in order within a path
- Take notes — you'll reference them on HTB later
