## Exam Details

- **Code**: N10-009 (current)
- **Questions**: 90 (max)
- **Time**: 90 minutes
- **Passing score**: 720/900

## Key Topics

- OSI / TCP-IP model
- Ethernet and switching
- IP addressing and subnetting
- Routing protocols
- Wireless networking and security
- Network troubleshooting tools
- Cloud and virtualization basics

## Recommended Before

CompTIA A+ or equivalent hands-on experience with basic networking.
