## Exam Details

- **Code**: SY0-701 (current)
- **Questions**: 90 (max)
- **Time**: 90 minutes
- **Passing score**: 750/900
- **Cost**: ~$392 USD

## Domains (SY0-701)

1. General Security Concepts (12%)
2. Threats, Vulnerabilities & Mitigations (22%)
3. Security Architecture (18%)
4. Security Operations (28%)
5. Security Program Management & Oversight (20%)

## Tips

- Know the acronyms cold
- Performance-based questions (PBQs) come first — don't panic
- Flag and return to hard questions
- Study the CompTIA objectives document
