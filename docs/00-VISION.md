# Cyber Atlas Vision

Version: 2.0
Status: Accepted

---

# Vision

Cyber Atlas is an interactive engineering knowledge graph that documents my journey from a computer science student to a software engineer and cybersecurity professional.

It is **not**:

- a blog
- a tutorial collection
- copied notes
- a certification dump

Instead, it is a structured, interconnected knowledge base inspired by engineering documentation systems, Obsidian knowledge graphs, and software architecture RFCs.

Every concept is represented as a node.

Every relationship is represented as an edge.

Every topic has history, theory, implementation, debugging, practical labs, and real-world applications.

---

# Mission

Understand computers instead of memorizing them.

Every technology should answer one question:

> What problem forced engineers to invent this?

Learning follows the historical evolution of computing rather than isolated definitions.

---

# Core Principles

## 1. Learn Chronologically

Topics are introduced in the order they became necessary.

Example

Internet

↓

DNS

↓

TCP

↓

HTTP

↓

Servers

↓

Docker

↓

Kubernetes

↓

Cloud

instead of random tutorials.

---

## 2. Every Topic Must Earn Its Place

No topic is introduced unless the previous one exposes the problem it solves.

---

## 3. Everything Connects

Every note links to:

- prerequisites
- related concepts
- technologies that use it
- technologies built upon it

The knowledge graph should naturally grow over time.

---

## 4. Theory + Practice

Every topic contains:

- history
- implementation
- commands
- debugging
- practical lab
- interview questions
- references

Learning ends only after practical implementation.

---

## 5. Production First

Concepts are explained using real production systems.

Examples include:

- AWS
- Kubernetes
- Docker
- Linux
- Cloudflare
- GitHub
- Netflix

---

## 6. Build While Learning

Cyber Atlas itself is a demonstration project.

Every topic should eventually be reflected in:

- the Atlas website
- labs
- projects
- the vulnerability scanner
- future production deployments

---

# Long-Term Goal

Cyber Atlas should eventually become a public engineering encyclopedia documenting several years of continuous learning.

It should be valuable to:

- myself
- recruiters
- developers
- cybersecurity students
- future contributors

---

# Success Criteria

A visitor should be able to:

- navigate concepts visually
- understand relationships
- reproduce labs
- learn progressively
- see practical implementations
- understand why technologies exist

without needing external notes.
